# Luxury Wedding Invitation Starter

Responsive luxury wedding invitation website, built with HTML/CSS/JS.

## Preview
Open `index.html` in a browser. Remote sample photos and Google Fonts require an internet connection.

## Customise
- Edit `wedding` in `script.js` for names, date, and WhatsApp RSVP number.
- Update ceremony/reception text in `index.html`.
- Replace sample image URLs in `style.css` with client-approved photos.
- Add licensed music as `assets/music.mp3`.
- Link your guest upload page from the gallery button (currently `guest-upload.html`).

## Notes
This is a front-end starter. The gallery approval flow and durable RSVP storage require backend integration. Do not publish private client data in a public repository.
